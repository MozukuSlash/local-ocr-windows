# Local OCR — Windows 11 用試作版 0.5

0.5では、選択セルの青い強調表示、列幅・行高のドラッグ変更、認識枠の削除、同じ範囲の一括読み取りを追加しました。

## セルの表示と認識枠の削除

- セルをクリックすると青色になります。別のボタンにフォーカスが移っても選択色を保ちます。
- 右側の表の列番号・行番号の境界をドラッグすると列幅・行高を変更できます。境界のダブルクリックで内容に合わせて自動調整します。変更したサイズは、その表を選び直しても保持します。これらは編集画面の表示設定で、コピー・Excel保存の列幅や行高には反映しません。表の行列数が変わった場合は自動調整に戻ります。
- 原本の認識枠を選び「認識枠を削除」を押すと、現在のレイヤーの結果から削除します。Ctrl+クリックで複数選択できます。原本にフォーカスがある場合はDeleteキーも使えます。「元に戻す」で復元できます。原本画像は変更しません。行レイヤーと段落・表レイヤーは独立しています。
- 手動で囲った読み取り範囲を取り消す場合は「範囲を解除」を使います。

## 同じ範囲を100ページなどに適用する

1. 基準にするページで「範囲を指定」を押し、読み取りたい場所を囲みます。
2. 「同じ範囲をまとめて読取」を押し、全ページ／現在の文書／ページ番号指定を選びます。番号指定は左の一覧の上から数えた番号で、例は「1-10,15」です。
3. 「まとめて読み取る」で開始します。元ページの用紙内の相対位置を、対象ページの画像サイズに合わせて拡大・縮小して使います。配置や向きが大きく違う帳票を自動で位置合わせする機能ではありません。
4. 進捗を表示し、ページを1枚ずつ画像化・読み取りします。「途中停止」は現在のページが終わった時点で停止します。処理済みの結果は残し、未処理ページは変更しません。
5. 失敗・文字なしのページの既存結果は保持します。終了時に更新・文字なし・失敗の件数を表示します。修正を戻す場合は対象ページを開いて「元に戻す」を押してください。

範囲内に完全に収まる既存の枠を更新し、一部だけ重なる枠は保持します。未解析ページの範囲だけを読んだ場合は「範囲読み取り済み」と表示します。そのページの範囲外を解析した意味ではなく、エクスポートには実際に読み取った結果だけが入ります。用紙や範囲が小さすぎるページは失敗として続行します。読み込み上限は合計200ページです。

0.4.1では「サンプル」メニューに、同じ架空の請求書の4段階（きれいな原稿・約2度の傾き・約4度の傾きと低画質・約7度の傾きと強い劣化）を追加しました。スキャン風サンプルに認識済みの枠・文字はなく、「このページを読み取る」で実際のOCRを試せます。配布フォルダーの「スキャン風サンプル」には4枚のJPG、画像のみの4ページPDF、正解の表CSV・JSON、画質比較画像を同梱しています。実際のスキャナーで取得した画像ではなく、傾き・低解像度・濃淡ムラ・にじみ・ノイズ・JPEG圧縮を合成したテスト用データです。

0.4では「元に戻す・やり直す」、表の行・列の追加削除とセルの結合・解除、範囲をドラッグして再読み取りする機能を追加しました。

## 表の修正と再読み取り

- 「元に戻す」「やり直す」：現在のページの文字修正、セル修正、表構造の変更、読み取り結果をページごとに最大50操作戻せます。Ctrl+Z／Ctrl+Y／Ctrl+Shift+Zでも操作できます。セル内で入力中の文字は、編集を確定してから戻してください。コピー内容・保存済みファイルは巻き戻しません。
- 「行・列を編集」：表のセルを選び、上／下に行、左／右に列を追加、選択した行／列を削除できます。すべての行・列の削除はできません。結合セルの先頭が削除されても、結合部分が残る場合は残った先頭セルに文字を引き継ぎます。
- 「セルを結合」：隙間のない四角形にセルを選んで結合します。元の文字は読み順に改行でまとめます。「結合を解除」は文字を先頭セルに残して解除します。元の各セルの文字への復元は「元に戻す」を使います。
- 「範囲を指定」：原本上でドラッグし、「この範囲を読み取る」で読み直します。範囲に完全に収まる既存の枠を更新します。一部だけ重なる枠は保持されるため、表全体を置き換える場合は表の外側まで囲ってください。範囲に文字がなければ既存の結果を保持します。結果の座標は原本上の位置に戻して表示します。
- 修正内容と履歴はメモリ上だけに保持し、文書を閉じると破棄します。必要な結果はエクスポートしてください。

0.3.1ではボタンを押したときに色が変わり、押し込まれる見た目になります。コピー成功後はボタンが約1.8秒間「✓ コピーしました」に変わります。画面下の通知にはコピーした行数・列数、保存・読取完了などを約4秒間表示します。セル未選択など、操作を完了できない場合は理由を表示します。

0.3では右側の一覧から認識した表を選択し、「表をコピー」でExcel・Googleスプレッドシートへ貼り付けられます。認識された結合セルをプレビュー・HTMLコピー・Excel保存で保持します。文字はダブルクリックで修正できます。日本語・空欄・セル内改行・先頭ゼロを含む出力と結合セルを自動テストしています。貼り付け先のアプリでの実動作は未検証です。

Indra OCR 1.1.2 を端末内で実行し、PDF・画像上の認識枠をクリックして修正・コピーするアプリです。

## 起動と操作

1. 配布フォルダー `LocalOCR` を丸ごと展開し、`LocalOCR.exe` を開きます。Python のインストールは不要です。`_internal` は移動・削除しないでください。
2. 「PDF・画像を開く」またはドラッグ＆ドロップで文書を追加します。
3. ページを選び「このページを読み取る」を押します。ページごとに処理します。
4. 原本に自動表示された枠をクリックします。Ctrl＋クリックで複数選択できます。「段落・表の枠」「行の枠」を切り替えられます。
5. 右側の「認識した表を選ぶ」一覧または原本の表の枠から表を選びます。文字をダブルクリックで修正し、「表をコピー」→Excel・Googleスプレッドシートで貼り付けます。表の一部は右側のセルを選んで「表の選択セルだけコピー」できます。部分コピーでは全体が選択された結合セルだけを保持します。
6. 「エクスポート…」で対象（選択した枠／表示中のページ／読み取り済みの全ページ）と形式を選び、保存先を指定します。作業内容の自動保存はありません。

## エクスポート

- Excel（.xlsx）：ページごとにシートを分けます。全セルを文字列として保存し、先頭ゼロ・長い番号・数式に見える文字列を保持します。計算が必要な列はExcel側で確認して数値へ変換してください。
- CSV：1ページなら認識データのみ。複数ページなら先頭に文書番号とページ番号を付けます。
- テキスト：本文とタブ区切りの表。複数ページでは区切り見出しを付けます。
- Markdown：本文と表。表の先頭行を勝手に見出し扱いしないよう、空の見出しを付けます。
- JSON：修正後の文字・表・座標・信頼度。原本画像とファイルパスは含めません。作業再開用の読み込み機能ではありません。

現在のレイヤー（行／段落・表）の修正内容を出力します。そのレイヤーに領域がないページだけ、もう一方の領域を使用します。「全ページ」は読み取り済みのみで、未解析ページ数を画面に表示します。表の修正値は全形式に反映します。元のファイル名は出力せず、文書番号は読み込み順です。HTMLコピーとExcel保存は認識された結合セルを保持します。TSV・CSV・Markdownでは結合部分を空欄に展開します。JSONにはゼロ始まりの行・列・行数・列数でspansを含めます。

「サンプル」→「操作サンプル（認識枠付き）」は架空データと手作業の枠による操作デモです。「スキャン風」の4種類は未解析の原稿から実際に読み取りを試すためのサンプルです。読み取り結果が正解の表と異なる場合は、セルや表構造を修正して確認してください。低画質ほど正確に読めることを保証するものではありません。

## この試作版の限界

- 認識は行／段落／表単位です。原本上での単語ごと・表セルごとのクリックには未対応です。
- 行レイヤーと段落・表レイヤーの修正は独立しています。修正とコピーは同じレイヤーで行ってください。
- 複雑な表・手書き・薄い文字では誤認識や列ずれがあります。結合セルはエンジンがHTMLで返した場合、または手動で結合した場合に保持されます。元の列幅・背景色・フォントは再現せず、読みやすい標準書式と罫線で出力します。
- Excel向けHTMLでは全セルを文字列指定しますが、実際のExcel・Googleスプレッドシートへの貼り付けはこの環境では未検証です。貼り付け先によって結合・改行・文字列の指定が変わる場合があります。先頭ゼロ・日付・数式扱いを厳密に保持する必要がある場合はExcel形式で保存して開いてください。Googleスプレッドシートに貼り付け・取り込みしたデータはGoogle側に送信されます。
- CSVは数式開始文字をアポストロフィで保護します。CSVの先頭ゼロはExcelの「データから取り込み」で列を文字列として指定してください。
- 最大200ページ、1ページ3,000万画素。指定範囲の一括処理に対応しています。ページ全体の一括読み取り、検索可能PDF、電子カルテへの自動登録は未実装です。
- 署名のない評価用ビルドです。患者情報を用いる本番運用のセキュリティ適合を保証するものではありません。

## データの扱い

- モデル同梱。起動時にローカルのSHA-256を検証し、不足・不一致なら停止します（署名による真正性の保証ではありません）。
- 外部API、利用状況送信、自動更新、ローカルWebサーバーはありません。Pythonのネットワーク接続・名前解決・待受けを拒否し、ONNX Runtimeのテレメトリーを無効にします。
- 原本の読み込み・画像化・OCR結果はメモリ上で扱い、アプリから一時画像や患者情報ログを書き出しません。エクスポートとクリップボードコピーは利用者の操作でのみ行います。
- エクスポート時は保存先フォルダー内の一時ファイルに書き込み、完了後に指定ファイルへ置き換えます。通常の失敗時は破棄しますが、OS強制終了時の残存も含め保存先を適切に管理してください。
- これはネイティブライブラリを含む通信の完全監査やOSレベルの遮断の代替ではありません。本番配布時は社内管理者による外向き通信遮断・端末暗号化・保存先権限・バックアップ設定の確認が必要です。
- OSのページファイル、クラッシュダンプ、クリップボード履歴、クラウド同期はアプリだけでは制御できません。クリップボード履歴・端末間同期は社内設定で無効にしてください。
- 「コピー内容を消去」と終了時には、現在のクリップボードが本アプリのコピー内容と一致する場合だけ消去します。過去の履歴を消すものではありません。
- モデル取得・依存ソフトの準備は開発時にのみネットワークを使います。患者データは配布フォルダーや開発用フォルダーに含めないでください。

## 再ビルド

Windows / Python 3.12を使用します。

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements-lock.txt
.venv\Scripts\python prepare_models.py
.venv\Scripts\python collect_licenses.py
.venv\Scripts\python -m pytest -q test_app.py test_export.py test_page_view.py test_tables.py test_editing.py test_scan_samples.py test_batch.py --basetemp validation/test-tmp
.venv\Scripts\python smoke_test.py
.venv\Scripts\python -m PyInstaller --noconfirm --distpath dist-v0.5 LocalOCR.spec
.venv\Scripts\python package_release.py --version 0.5
```

モデルは `datalab-to/indra-ocr` の `v1.1.0` を指定。依存ソフトの通知は `_internal/licenses`、モデルの利用条件は `_internal/models/LICENSE` に同梱します。Indraのコードとモデルは別ライセンスです。PySide6/Qtのライセンス通知も同梱し、DLLを個別ファイルとして配布します。

スキャン風サンプルはscan_samples.pyでメモリ上に生成します。単独配布用のJPG・PDFを再生成する場合は、reportlabを追加した開発環境でprepare_scan_samples.pyを実行します（アプリの起動・OCRにはreportlab不要）。
