# Local OCR — Windows 11 用試作版 0.2.1

0.2.1ではPDF・画像の縮小表示を改善しました。表示倍率に合わせた高品質な縮小画像をメモリ上で作り、細い文字・罫線の欠けを抑えます。OCR用画像と枠の座標には影響しません。

Indra OCR 1.1.2 を端末内で実行し、PDF・画像上の認識枠をクリックして修正・コピーするアプリです。

非公式配布版です。[Indra OCR](https://github.com/datalab-to/indra)と[モデルの提供元](https://huggingface.co/datalab-to/indra-ocr/tree/v1.1.0)はDatalabです。モデルの重みは変更していません。利用・再配布には同梱の `NOTICE.txt` と `MODEL-LICENSE.txt` の条件が適用されます。モデルの商用利用には組織の売上・資金調達額や競合用途などの条件があるため、誰でも無条件に無料で使える配布物ではありません。

## 起動と操作

1. 配布フォルダー `LocalOCR` を丸ごと展開し、`LocalOCR.exe` を開きます。Python のインストールは不要です。`_internal` は移動・削除しないでください。
2. 「PDF・画像を開く」またはドラッグ＆ドロップで文書を追加します。
3. ページを選び「このページを読み取る」を押します。ページごとに処理します。
4. 原本に自動表示された枠をクリックします。Ctrl＋クリックで複数選択できます。「段落・表の枠」「行の枠」を切り替えられます。
5. 右側で文字・表を修正し「選択した枠をコピー」。Excelに貼り付けます。表の一部は右側のセルを選んで「表の選択セルだけコピー」できます。
6. 「エクスポート…」で対象（選択した枠／表示中のページ／読み取り済みの全ページ）と形式を選び、保存先を指定します。作業内容の自動保存はありません。

## エクスポート

- Excel（.xlsx）：ページごとにシートを分けます。全セルを文字列として保存し、先頭ゼロ・長い番号・数式に見える文字列を保持します。計算が必要な列はExcel側で確認して数値へ変換してください。
- CSV：1ページなら認識データのみ。複数ページなら先頭に文書番号とページ番号を付けます。
- テキスト：本文とタブ区切りの表。複数ページでは区切り見出しを付けます。
- Markdown：本文と表。表の先頭行を勝手に見出し扱いしないよう、空の見出しを付けます。
- JSON：修正後の文字・表・座標・信頼度。原本画像とファイルパスは含めません。作業再開用の読み込み機能ではありません。

現在のレイヤー（行／段落・表）の修正内容を出力します。そのレイヤーに領域がないページだけ、もう一方の領域を使用します。「全ページ」は読み取り済みのみで、未解析ページ数を画面に表示します。表の修正値は全形式に反映します。元のファイル名は出力せず、文書番号は読み込み順です。結合セルは空欄に展開します。

「サンプル」は架空データと手作業の枠による操作デモです。実際のOCRを確認する場合は、サンプル表示後に「このページを読み取る」を押してください。

## この試作版の限界

- 認識は行／段落／表単位です。原本上での単語ごと・表セルごとのクリックには未対応です。
- 行レイヤーと段落・表レイヤーの修正は独立しています。修正とコピーは同じレイヤーで行ってください。
- 複雑な表・手書き・薄い文字では誤認識や列ずれがあります。結合セルはコピー時に空欄へ展開します。
- Excel向けHTMLでは全セルを文字列指定しますが、実際のExcelへの貼り付けはこの環境では未検証です。先頭ゼロ・日付・数式扱いの有無を確認してください。プレーンテキスト貼り付け先にはこの指定が届きません。
- CSVは数式開始文字をアポストロフィで保護します。CSVの先頭ゼロはExcelの「データから取り込み」で列を文字列として指定してください。
- 最大200ページ、1ページ3,000万画素。全ページ一括処理、検索可能PDF、電子カルテへの自動登録は未実装です。
- 署名のない評価用ビルドです。患者情報を用いる本番運用のセキュリティ適合を保証するものではありません。

## データの扱い

- モデル同梱。起動時にローカルのSHA-256を検証し、不足・不一致なら停止します（署名による真正性の保証ではありません）。
- 外部API、利用状況送信、自動更新、ローカルWebサーバーはありません。Pythonのネットワーク接続・名前解決・待受けを拒否し、ONNX Runtimeのテレメトリーを無効にします。
- 原本の読み込み・画像化・OCR結果はメモリ上で扱い、アプリから一時画像や患者情報ログを書き出しません。エクスポートとクリップボードコピーは利用者の操作でのみ行います。
- エクスポート時は保存先フォルダー内の一時ファイルに書き込み、完了後に指定ファイルへ置き換えます。通常の失敗時は破棄しますが、OS強制終了時の残存も含め保存先を適切に管理してください。
- これはネイティブライブラリを含む通信の完全監査やOSレベルの遮断の代替ではありません。本番配布時は社内管理者による外向き通信遮断・端末暗号化・保存先権限・バックアップ設定の確認が必要です。
- OSのページファイル、クラッシュダンプ、クリップボード履歴、クラウド同期はアプリだけでは制御できません。クリップボード履歴・端末間同期は社内設定で無効にしてください。
- 「コピー内容を消去」と終了時には、現在のクリップボードが本アプリのコピー内容と一致する場合だけ消去します。過去の履歴を消すものではありません。
- モデル取得・依存ソフトの準備は開発時にのみネットワークを使います。患者データは配布フォルダーや開発用フォルダーに含めないでください。

## 再ビルド

Windows / Python 3.12を使用します。

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements-lock.txt
.venv\Scripts\python prepare_models.py
.venv\Scripts\python collect_licenses.py
.venv\Scripts\python -m pytest -q --basetemp validation/test-tmp
.venv\Scripts\python smoke_test.py
.venv\Scripts\python -m PyInstaller --noconfirm --distpath dist-v0.2.1 LocalOCR.spec
```

モデルは `datalab-to/indra-ocr` の `v1.1.0` を指定。依存ソフトの通知は `_internal/licenses`、モデルの利用条件は `_internal/models/LICENSE` に同梱します。Indraのコードとモデルは別ライセンスです。PySide6/Qtのライセンス通知も同梱し、DLLを個別ファイルとして配布します。
